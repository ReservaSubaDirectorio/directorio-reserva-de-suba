# Directorio Reserva de Suba

Sitio estático para publicar en Cloudflare Pages desde GitHub.

## Archivos
- index.html
- styles.css
- app.js
- config.js   ← aquí se editan teléfonos y el link del manual
- logo.png

## Ruta
Editar → git add / commit / push en GitHub → Cloudflare Pages publica → QR apunta a la URL .pages.dev
